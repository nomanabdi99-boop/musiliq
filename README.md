# 🎵 LiquidStream

A premium, minimalist mobile music streaming application featuring a modern **Liquid Glass** (glassmorphism) design aesthetic. Users can search, browse, and stream high-quality music freely, with built-in capabilities for offline playback.

---

## ✨ Features

* **🎛️ Liquid Glass UI:** A stunning, dark-mode user interface utilizing semi-transparent glassmorphism panels, soft blurs, and glowing accents.
* **🔍 Free Music Discovery:** Integrated search bar and dynamic music cards to browse trending artists, tracks, and albums seamlessly via open-source music APIs.
* **📱 Native-Feel Controls:** Large, centered neon action buttons (Play/Pause/Stop), an interactive scrubbing progress bar, and a smooth volume slider.
* **💾 Offline Mode:** Toggle switch functionality allowing users to cache or download audio data directly to local storage for network-free playback.

---

## 🛠️ Tech Stack & Architecture

* **Frontend Framework:** React / Vite (or Next.js)
* **Styling:** Tailwind CSS (with custom backdrop-filter utilities for glassmorphism effects)
* **State Management:** Context API / Lucide React (for premium iconography)
* **Audio Core:** HTML5 Audio API with custom buffering and caching logic
* **Data Source:** Jamendo API / Open-source music directories
